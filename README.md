# UniConnect NG 🇳🇬

The Student Empowerment Platform for Nigerian Universities.

## Features
- Community Feed per Institution
- Digital Library with Offline Downloads  
- CGPA Calculator for 4.0 and 5.0
- Knowledge Test Center with Leaderboard
- 260+ Nigerian Institutions Pre-seeded

## Tech Stack
Next.js 14 + TypeScript + TailwindCSS + Prisma + PostgreSQL

## Setup
1. `npm install`
2. Copy `.env.example` to `.env`
3. `npx prisma migrate dev`
4. `npm run dev`
